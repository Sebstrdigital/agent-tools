# Team

Selection of Team authorizes preparation, not execution. Inspect rules, source and existing changes; recover relevant decisions.

## Prepare

Default to a 3–5 sentence task: purpose, change, observable acceptance and important boundaries. Link project knowledge rather than replaying history. Use one compact task record (Markdown or existing JSON) with a short Agreement section; obtain approval of that actual Agreement before launching. Brief/Plan/Agreement are responsibilities, not three mandatory files. Use `references/templates/task.md` if helpful; other templates are optional.

State scope, checks, permissions and limits once. Approval covers investigation, edits, checks and bounded repairs without per-edit approval. Material changes need renewed approval and a short dated note.

Supply relevant rules/context; child discovery is denied. Workers need purpose, constraints and acceptance. No mandatory reading manifests or read receipts. Excerpts must not omit governing constraints. Keep logs on disk; retrieve question-driven bounded evidence. Codemode must filter, not merely batch raw reads. Reuse unchanged context.

## Execute

Read `references/delegation.md` before delegating. Prefer vertical slices with IDs, outcomes, dependencies, ownership and parallel eligibility. Each slice gets a fresh builder run, never bundled with other slices. Start only after prerequisite acceptance; parallel eligibility is metadata, not launch permission. Use fresh sequential builder -> no-edit validator -> inspection-only reviewer per slice. Retain final integrated validation/review. No nesting, parallel workers or grant widening. A routine baseline does not need a separate three-role cycle.

The lead inspects changes and explicitly accepts. Red task-owned checks/findings trigger bounded builder repair, not routine customer stops. Allow at most three focused repair cycles unless approval is stricter; renew affected checks/review and continue approved dependencies. If the same defect survives two cycles, the third uses a fresh stronger same-role builder context with diagnosis before edits. Follow the lean guide's escalation controls; no allowance reset or retroactive approval expansion. Stop for material decisions, missing authority, no progress or exhausted agreed limits. Missing checks are not passes.

Do not require unrelated applications to close or control them. Isolate live-side-effect tests or propose precise exclusions with honest coverage gaps; required-check changes need approval. Ask before stopping the application under development.

Before sensitive tests run, verify isolation at the effective execution boundary (the launched process/configuration), not just the invoking shell. If isolation is unverified or fails, fix the validation setup before proceeding. Obtain the required valid baseline before edits; a later reconstructed baseline is corrective evidence, not retroactive compliance. This is a targeted preflight, not a reading manifest or global application inventory.

Use agreed ceilings, not invented active-minute accounting or per-role pools. Fixed timeouts and optional declared assignment/escalation limits remain binding; no automatic resets/replacements.

## Progress

Keep one canonical Plan: slice state, candidate, decisions, checks, blockers and evidence pointers. Worker completion is not acceptance. Use concise handoffs, not transcripts. Inspect complete changes in bounded sections; summaries do not replace review. The widget is a projection; retain unresolved work. See `references/authority-and-state.md` for recovery.

Record concise Munin outcomes and exact-ID handoffs; relevance is not recency. Final reporting covers changes, checks actually run and remaining limitations. Commit/push/install/deploy need permission unless already included. Do not normally implement application code as the Team lead.

Consult [runtime details](../../docs/lean-workflows.md) as needed. Legacy transport has no validator; supply one separately. Scout cannot replace validation/review. Runtime grants, routing and ownership are unchanged.
